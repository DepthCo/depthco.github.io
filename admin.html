Conexión con GitHub

Para que el botón Guardar cambios publique directo en la web, el panel necesita permiso para escribir en tu repositorio. Esto se configura una sola vez en cada dispositivo (compu o celular).

  1. Entrá a github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. En Repository access elegí Only select repositories y marcá el repo de la web.
  3. En Permissions → Repository permissions → Contents elegí Read and write.
  4. Generalo, copialo y pegalo acá abajo junto con tu usuario y el nombre del repo.

El token queda guardado solo en este navegador. No lo compartas: con él se puede modificar la web.

Sin conexión

Si preferís no conectar GitHub, podés descargar los archivos con tus cambios y subirlos a mano al repo (en GitHub: Add file → Upload files, en la misma carpeta).

Las fotos solo se pueden subir desde el panel con la conexión activa. Sin conexión, subilas a la carpeta img/productos/ y escribí la ruta en el campo de la foto.
